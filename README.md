### Hi, I'm Rabi Raj Yadav 👋

## 🧭 About

I build enterprise software and teach AI at **Nepal Telecom (NTC)**, in the IT Department's Software & Security Wing.

Most of my work lives where telecom operations meet modern platforms: Go microservices behind customer-facing systems, AI assistants grounded in company knowledge, and the infrastructure to run them, plus the courses that teach engineers to build the same.

- 🏗️ Building **UTS**, a microservices complaint and fault-ticketing platform for Nepal Telecom (Go, Kafka, real-time dispatch)
- ⚡ Building **LPS Digital Nexus**, an enterprise platform for automating Lightning Protection System engineering projects
- 🤖 Shipped an **AI customer-support chatbot** for NTC, using RAG with automated knowledge-base updates
- 🛒 Built **GtradeA**, a cross-border e-commerce platform for Nepal, on web (React + Supabase) and mobile (Flutter)
- 🎓 Teaching **AI Agents in Practice** and **AI Engineer with PyTorch**
- 💬 Happy to talk about Go microservices, RAG and AI agents, pgvector search, Supabase, or Kubernetes
- 🌐 Portfolio → [rraj78502.github.io](https://rraj78502.github.io)
- 📫 Reach me at **rraj78502@gmail.com**

## 📌 Featured Projects

*Shipped products. Most is commercial work and its source isn't public.*

### 📞 UTS: Unified Ticketing System
Complaint and fault management for Nepal Telecom. Go microservices with Kafka, Centrifugo real-time updates, OTP login, SMS, audit and reporting, Vault secrets, Backstage catalog and Grafana observability.

### ⚡ LPS Digital Nexus
An enterprise cloud platform that automates Lightning Protection System (LPS) engineering projects, from design through delivery.

### 🤖 NTC Customer Support Chatbot
An AI assistant for Nepal Telecom customers. Answers come from retrieval-augmented generation (RAG) over a knowledge base that updates automatically.

### 🛒 GtradeA
Cross-border commerce for Nepal: a storefront plus 1688/Alibaba sourcing, a pricing engine with HS codes, fees and exchange rates, eSewa checkout, a PWA, and a Flutter mobile app.

### 👔 Luxury Fashion Platform
Next.js storefront and Go API, with AI semantic search and outfit pairing on PostgreSQL + pgvector (HNSW).

### 🗺️ Balen: Public Procurement Explorer
Nepal e-GP tender scraper and bid search, with province → district → municipality choropleth maps.
